# 완드 정리 사용 가이드

[English](README.md)

입력창 옆 **마법봉 메뉴**를 정리해 주는 실리태번 확장입니다.
안 쓰는 항목은 숨기고, 나머지는 폴더로 묶을 수 있어요. 휴대폰에서 쓰기 편하게 만들었습니다.

---

## 1. 설치하기

1. 실리태번 위쪽의 **확장 프로그램**(퍼즐 모양 아이콘)을 누릅니다.
2. **Install Extension**을 누릅니다.
3. 이 저장소 주소를 붙여 넣고 **Install**을 누릅니다.

   ```text
   https://github.com/spaceship4415/st-wand-trim
   ```

---

## 2. 메뉴 정리하기

마법봉 메뉴를 열면 맨 아래에 **메뉴 정리**가 있어요. 누르면 편집이 시작됩니다.
편집 중에는 항목을 눌러도 실행되지 않고, 줄이 커져요.

- **오른쪽 눈 아이콘을 누르면** 바로 숨기거나 다시 보여요. 숨긴 항목은 편집 중엔 흐리게 줄이 그어져 보이고, 편집을 끝내면 사라져요.
- **항목의 나머지 부분을 누르면** 바로 아래에 폴더 창이 열려요.
  - **폴더**: 폴더 밖으로 빼거나, 만들어 둔 폴더 중 하나에 넣어요.
  - **새 폴더**: 이름을 쓰고 **만들어 넣기**를 누르면 폴더를 만들고 그 항목을 바로 넣어요.
- **폴더 안 항목의 왼쪽 손잡이(⠿)를 끌면** 폴더 안에서 자리를 옮겨요. 손잡이가 아닌 곳을 끌면 평소처럼 메뉴가 스크롤돼요.
- **폴더를 누르면** 이름 바꾸기, 위로/아래로 옮기기, 폴더 지우기를 할 수 있어요.
  폴더를 지우면 안에 있던 항목은 밖으로 나와요. 없어지지 않아요.
- **정리 끝내기**를 누르거나 메뉴 바깥을 누르면 편집이 끝나요.

---

## 3. 평소에 쓰기

- 폴더를 누르면 메뉴 안에서 바로 펼쳐지고 접혀요. 새로고침하면 다시 접힌 상태로 시작해요.
- 안의 항목을 다 숨긴 폴더는 보이지 않아요.
- 메뉴 순서는 **폴더 밖 항목 → 폴더들 → 메뉴 정리**예요. 폴더 안 항목은 직접 옮기기 전까지 원래 메뉴 순서를 따르고, 새로 넣은 항목은 맨 뒤로 가요.
- 다른 확장이 나중에 추가한 항목도 똑같이 숨기거나 폴더에 넣을 수 있어요.

---

## 4. 알아 두면 좋은 것

- 다른 확장의 메뉴 항목을 실제로 옮기지 않고, 화면에 보이는 순서와 표시만 바꿔요.
  그래서 다른 확장이 자기 항목을 찾거나 바꿔도 문제가 생기지 않아요.
- 항목은 id로 기억해요(id가 없으면 글자로). 어떤 확장이 업데이트로 항목 id를 바꾸면,
  그 항목은 새 항목처럼 다시 보이게 돼요.

---

## 5. 설정은 어디에 저장되나요?

실리태번의 `settings.json`이 아니라 따로 파일에 저장해요.

```text
data/<사용자>/user/files/st-wand-trim-settings.json
```

확장 관리에서 이 확장을 지우면 이 파일도 함께 지워져요.
